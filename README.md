# Semester

A private college dashboard: assignments, calendar, to-dos, contacts, and daily finance news.

**Open it:** https://walidalmuhaidib-create.github.io/semester/

## Put it on an iPhone

1. Open the link above in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open **Semester** from the Home Screen. It runs full-screen and works offline.

Everything you enter stays on your phone. Nothing is sent anywhere. Use **Back up** on the Home screen now and then to save a copy to Files or iCloud Drive.

## Updating

Edit the files and push to `main`. When you change `index.html`, `styles.css` or `app.js`, bump `CACHE` in `sw.js` so phones get the new version. Phones pick up the update the second time the app is opened.
